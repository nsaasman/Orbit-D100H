# Volgende release / Next release

## Nederlands

Orbit D100H ondersteunt nu Nederlands, Engels, Duits, Frans en Spaans.
Kies de taal bovenaan het venster. De interface, het systeemvakmenu,
statusmeldingen en de sneltoetseditor wisselen direct mee. De keuze blijft
na herstart behouden. Zonder opgeslagen voorkeur volgt de app de
Windows-weergavetaal, met Engels als terugvaltaal.

Taalwissel behoudt onopgeslagen profielbewerkingen en de geselecteerde knop.
Een lopende sneltoetsopname wordt eerst geannuleerd; de vorige combinatie en
pauzestand blijven behouden. Bestaande instellingen blijven bruikbaar.

De projectuitleg is beschikbaar in het Nederlands en Engels. De Windows-download
bevat alle vijf talen; een losse taaldownload is niet nodig. Pak de volledige
ZIP uit en houd alle bestanden en taalmappen bij elkaar.

Windows-dialogen en systeemfoutdetails volgen Windows. Probe is niet volledig
vertaald. Deze notities horen bij de volgende release en maken zelf geen release aan.

## English

Orbit D100H now supports Dutch, English, German, French and Spanish.
Choose a language at the top of the window. The interface, system tray menu,
status messages and shortcut editor update immediately. Your choice is kept
after restarting. Without a saved preference, the app follows the Windows
display language and falls back to English for unsupported languages.

Changing language preserves unsaved profile edits and the selected button.
Any shortcut recording is cancelled first, keeping the previous binding and
pause state. Existing settings remain compatible.

Project documentation is available in Dutch and English. The Windows download
includes all five languages; no separate language download is needed. Extract
the complete ZIP and keep all files and language folders together.

Windows dialogs and system error details follow Windows. Probe is not fully
translated. These notes are for the next release and do not create a release themselves.
